**Badge** — compact status/category label. Sentence case: all caps are barred from digital channels [BG25 p.25]. Soft-tint by default; pass `solid` for a filled chip.

```jsx
<Badge tone="teal">In stock</Badge>
<Badge tone="sky" solid>New</Badge>
<Badge tone="danger">Backordered</Badge>
```

Tones: `navy`, `sky`, `green`, `teal`, `purple`, `gray`, `warning`, `danger`.
